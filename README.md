# Attendance Management System Starter

This workspace gives you a practical starting point for a MERN-based attendance system with:

- fingerprint attendance via HID DigitalPersona 4500
- face recognition via webcam
- Node/Express backend
- React frontend
- MySQL schema
- a separate Java biometric bridge for the fingerprint SDK

## Project layout

- `backend` - main Node/Express API
- `frontend` - React/Vite operator and admin UI
- `biometric-bridge-java` - Java service that talks to the HID SDK
- `face-service-python` - Python service for face enrollment and verification
- `database` - SQL schema and migration helpers
- `docs` - step-by-step setup guide
